LASTLIGHT 0.9.0-rc.1 — WINDOWS x64 PRERELEASE

1. Extract the entire ZIP to a normal writable directory.
2. Launch Run-Lastlight.bat or Lastlight.exe.
3. The new colony begins paused: Space resumes; 1/2/3 sets speed.
4. F10 saves, F11 loads, F12 shows help; WASD pans, wheel zooms.
5. Saves and crash logs: %LOCALAPPDATA%\Lastlight\Saves

Keep all DLLs and Assets together. This package includes the .NET runtime,
so there is no need to install the SDK. Windows x64 and an OpenGL-capable
graphics driver are the intended targets. Native Windows operation was not
independently verified during GitHub packaging.

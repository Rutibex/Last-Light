# Lastlight 0.9.0-rc.1 — Windows prerelease

Lastlight is a single-player science-fantasy colony simulator set beneath a failing sun. This release includes autonomous settlement management, multi-level building and survival systems, individual health and equipment, magic, regional exploration/diplomacy, persistent institutions and successors, and a five-stage solar campaign with five optional endings.

**Install:** Download `Lastlight-Windows-x64.zip`, extract everything to a folder, then start `Run-Lastlight.bat` or `Lastlight.exe`. Includes the Windows x64 .NET runtime; no SDK is needed. Requires an OpenGL-capable graphics driver.

**First time:** Game starts paused in Open Twilight. `Space` starts/stops time, `1`–`3` set speed, `WASD` pan, mouse wheel zoom, `F10` save, `F11` load, `F12` help.

**Important prerelease caveats:** The supplied executable has not been tested natively on Windows in this packaging pass. Some 1.0 content, broad modding, large colony benchmarks and accessibility features are incomplete. Back up saves before experimenting with mods; content hashes enforce compatibility. See `docs/ROADMAP.md` and `docs/TROUBLESHOOTING.md` in the source repository.

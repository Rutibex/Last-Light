# Controls

Default bindings below can be changed in **Menu → Key bindings**. Click a mapping, then press the desired key. These are the shipped defaults; controller input is not documented or verified.

| Action | Default |
| --- | --- |
| Pause / resume | `Space` |
| Normal / fast / very fast | `1` / `2` / `3` |
| Pan map | `W` `A` `S` `D` |
| Zoom at mouse pointer | Mouse wheel |
| Select an object | Left click |
| Multi-select / drag select | Shift / left drag |
| Context action / orders | Right click |
| Camera center on colony | `Home` |
| Rotate blueprint | `Q` / `E` |
| Select elevation | `[` / `]` (OEM brackets, keyboard layout dependent) |
| Draft selected settler | `R` |
| Toggle grid | `G` |
| Work / Schedule / Assign | `F1` / `F2` / `F3` |
| Animals / Wildlife / Research | `F4` / `F5` / `F6` |
| Quests / World / History | `F7` / `F8` / `F9` |
| Save / Load | `F10` / `F11` |
| Help | `F12` |
| Toggle Architect | `Tab` |
| Toggle Menu | `M` |
| Move keyboard focus between visible buttons | `Ctrl+Up` / `Ctrl+Down` |
| Activate focused button | `Enter` |

**Accessibility limits:** high contrast and button-focus navigation exist, but drawing, map painting and matrix cells require pointer interactions; the interface does **not** implement a screen-reader accessibility API.

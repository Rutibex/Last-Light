# Security policy

Lastlight 0.9.0-rc.1 is a prerelease desktop game. There is no promised security support window. If you identify a security problem, please **do not publish exploitation instructions or private user data** in a public bug report. Prefer GitHub's private security advisory reporting feature, if enabled for this repository; otherwise contact the repository maintainer privately through a published channel.

JSON content packs are intentionally data-only and validated, but player-created files should still be treated as untrusted inputs. Download releases and mods only from sources you trust.
